# Messenger Pro - PHP + MySQL

مشروع شات احترافي شبيه بالماسنجر مبني بـ **PHP + MySQL** بدون فريمورك.

## المميزات
- تسجيل دخول وإنشاء حساب جديد.
- شات بين المستخدمين بتصميم حديث.
- رفع صورة أو ملف داخل المحادثة.
- عرض الصور داخل الشات مباشرة.
- بحث عن المستخدمين بالاسم أو اسم المستخدم أو البريد.
- صفحة بروفايل جاهزة مع صورة شخصية وصورة غلاف ونبذة.
- قسم **تحليل الحساب**: عدد الرسائل، المرفقات، وعدد المحادثات.
- صفحة إعدادات لتعديل البيانات والصور وكلمة المرور.
- استخدام `PDO` و `prepared statements` للحماية الأساسية.

## التشغيل السريع
1. انسخ المجلد `messenger_pro` داخل مجلد السيرفر المحلي مثل `htdocs` أو `www`.
2. أنشئ قاعدة البيانات عبر استيراد الملف `install.sql` داخل phpMyAdmin أو من سطر الأوامر.
3. افتح الملف `config/config.php` وعدّل القيم التالية حسب بيئتك:
   - `APP_URL`
   - `DB_HOST`
   - `DB_PORT`
   - `DB_NAME`
   - `DB_USER`
   - `DB_PASS`
4. تأكد أن مجلدات الرفع قابلة للكتابة:
   - `uploads/avatars`
   - `uploads/covers`
   - `uploads/chat`
5. افتح الرابط في المتصفح، مثال:
   - `http://localhost/messenger_pro`

- `omar@example.com` أو `omar`

## هيكل المشروع
- `chat.php` صفحة المحادثات الرئيسية.
- `profile.php` صفحة الملف الشخصي.
- `settings.php` إعدادات الحساب.
- `api/get_messages.php` تحديث المحادثة تلقائياً.
- `helpers/` الدوال العامة ودوال الشات وعرض الرسائل.
- `assets/` ملفات التصميم والجافاسكربت والصور الافتراضية.
- `install.sql` بنية قاعدة البيانات والبيانات التجريبية.

## ملاحظات مهمة
- التطبيق يدعم المحادثات الفردية حالياً، وليس الجروبات.
- يمكن توسيعه بسهولة لإضافة:
  - WebSocket أو Pusher للتحديث اللحظي الكامل
  - نظام أصدقاء
  - إشعارات
  - رسائل صوتية
  - حذف الرسائل أو تعديلها
  - لوحة إدارة
- لو أردت نشره على استضافة فعلية، فعّل HTTPS وعدّل صلاحيات المجلدات وقيمة `APP_URL`.

## تحسينات مقترحة لاحقاً
- تحويل المحادثة إلى AJAX كامل عند الإرسال أيضاً.
- إضافة حالة الكتابة Typing indicator.
- إضافة معاينة عدد الرسائل غير المقروءة بشكل لحظي في الشريط الجانبي.
- ضغط الصور المرفوعة تلقائياً.
